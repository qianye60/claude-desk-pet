# 生图提示词（给 gpt-image 等 AI 绘图用）

要的图有三类，**只有第一类（成熟御姐）是必须做的**，其余是可选的锦上添花。

| 类别 | 放到哪里 | 必须 |
|---|---|---|
| 成熟御姐形态（10 张全身立绘） | `skins/yujie/` | 做了才会出现这个形态 |
| Claude 小图标（像素机器人） | `ui/clawd.png` | 否（没有就自动用像素机器人形态的图） |
| 额度卡片头图 | `ui/card_header.png` | 否 |

## 一、成熟御姐形态

### 出图规则（很重要）

1. **先出 `sit.png`，其余 9 张都用它当参考图**（图生图 / 角色参考 / “保持角色一致”），每次只改表情或姿势，参考强度中等偏高，服装、发型、发饰保持原样。
2. 画布统一 **1024×1536 竖版 PNG，透明背景**（只能出白底就用纯白，程序读图时会把和边缘相连的白底抠掉，衣服里的白色不受影响）。
3. **构图每张都一样**：全身，从头顶画到靴底，人物居中，**头顶高度、脚底位置、人物大小完全相同**。程序会按所有图共同的范围裁切，某张图肢体伸出去（比如手举过头顶），其余几张都会跟着缩小。所以举手也要**不超过头顶**。
4. 画面里不要有：文字、对话框、Zzz、爱心、汗滴、怒气符号、投影、地面、其他人物。这些由程序自己画。
5. **发饰左右别画反**：大花发饰在她自己的左侧，也就是画面右侧，AI 经常画反。出完检查一下。
6. 脚底要贴着画布底边（留 0~10 像素），因为她是“站在窗口上边缘”的，脚底就是窗口的边。

没有这些图的形态会自动用相近的代替（害羞/坏笑→开心，大笑→欢呼，思考→工作，打哈欠→睡觉/眨眼）。

做不过来也没关系：只有 `sit.png` 是必须的，缺的图程序会自动用相近的代替（欢呼/挥手→开心，鼓脸→担心，睡觉→眨眼…）。同一种表情可以做好几张变体，命名 `working_托腮.png`、`happy_眨眼.png` 这样，会随机或轮流用。

### 放进去

1. 把图放进 `skins/yujie/`（文件名按上表）
2. 把 `skin_template/yujie/skin.json` 复制进去（里面是名字、气质标签、AI 人格和显示大小）
3. 重启桌宠，右键菜单第三张形态卡片就变成她了。大小不合适改 `skin.json` 里的 `height`（默认 300，窗口上方放不下时会自动坐到右下角）

> 参考设计：你给的 [lmy414/ai-chan-sheets](https://github.com/lmy414/ai-chan-sheets) 里 Claude 娘设定图（该仓库是 CC BY-NC-SA 4.0，非商业、需署名、衍生需同协议）。上面的通用描述是照着那张设定图的服装写的；如果你的成图明显沿用了那套设计，请按它的协议署名并保持非商业使用。

## 二、Claude 小图标（可选）

放 `ui/clawd.png`，会出现在额度卡片标题旁、右键菜单顶部和托盘图标。不做也行，会自动用像素机器人形态的图。
